# weather-app
This project was created to help me practice the fundamentals of web development. It gave me hands-on experience working with HTML, CSS, and JavaScript, and helped me understand how each part connects to build a simple webpage.

## Technologies Used
- HTML5
- JavaScript (beginner level)

## Features
- A clean and simple webpage layout
- Basic styling to practice colors, spacing, and formatting
- A small JavaScript interaction to help me understand how scripts work

## How to Run
1. Clone or download the repo.
2.Open the index.html file in any web browser.
3.All files should load automaticallyno extra setup required.
## What I Learned
- How to structure a webpage using HTML
- How JavaScript connects to HTML and responds to user actions
- How CSS affects layout, spacing, and the overall look
- How to organize project files and write a clear README
